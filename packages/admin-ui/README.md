# Bell Streaming - Admin Dashboard

Admin dashboard for managing videos, users, and analytics.

## Features

- 📊 **Dashboard**: Overview statistics and recent activity
- 🎥 **Video Management**: View, search, and delete videos
- ⬆️ **Upload**: Upload new videos with drag-and-drop support
- 👥 **User Management**: Manage platform users
- 📈 **Analytics**: View platform analytics and insights

## Tech Stack

- React 18
- Vite
- TypeScript
- TailwindCSS
- React Router
- TanStack Query
- React Dropzone
- Recharts
- Shared UI Library

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Environment Variables

Create a `.env` file:

```env
VITE_API_BASE_URL=http://localhost:8081/api
VITE_CLOUDFRONT_URL=https://your-cloudfront-distribution.cloudfront.net
VITE_MAX_FILE_SIZE_MB=500
```
